# 原始观点模板

## 基本信息

- 主题：健康空调与用户体感
- 栏目：用户洞察 / 健康空气
- 目标平台：抖音 / 视频号 / 小红书
- 目标时长：30 秒 / 60 秒
- 目标人群：重视家人健康、关注舒适体感的家庭用户

## 原始观点

真正让用户愿意长期使用的健康空调，不只是参数更高，而是让人明显感觉到空气更舒服、温度更稳定、家人更安心。

## 用户痛点

- 普通空调容易直吹，老人和孩子体感不舒服。
- 只看温度数字，忽略了湿度、洁净度和空气流动。
- 用户很难理解复杂技术名词，需要可感知的体验表达。

## 核心表达

好空调不只是把房间变冷或变热，而是把空气调到让身体舒服的状态。

## 证据或素材

- 体感舒适：不直吹、不忽冷忽热。
- 健康空气：减少异味、灰尘和闷感。
- 家庭场景：老人午休、孩子学习、夜晚睡眠。

## 禁忌

- 不夸大医疗功效。
- 不使用未经验证的数据。
- 避免堆砌技术参数。
