# 初一品牌风格指南

## 品牌名

初一

## 账号定位

设计策略与产品观察。

## 表达风格

专业、清晰、有判断，但不端着。

## 内容态度

- 先讲判断，再讲理由。
- 少用空泛形容词，多用具体场景和产品细节。
- 不把复杂说成高级，要把复杂翻译成别人能理解的价值。
- 可以有个人观点，但要克制、可信、能落到产品和用户体验上。

## 语言规范

推荐表达：

- “这背后真正影响用户感受的是……”
- “行业常这样讲，但用户实际在意的是……”
- “设计策略不是把功能讲满，而是把价值讲清楚。”

避免表达：

- 过度鸡汤
- 夸张标题党
- 没有证据的绝对化判断
- 堆砌术语、参数和概念

## 视觉基调

- 专业、克制、有信息密度。
- 可使用深色背景、毛玻璃信息卡、细线框、对比表格。
- 避免过度冰冷的实验室感，也避免太活泼的营销海报感。
