# 内容栏目

## 空调设计观察

观察空调产品、交互、风感、健康表达、家居场景和用户体验之间的关系。

适合选题：健康空调、舒适风、柜机设计、用户体感、功能表达、卖点翻译。

## 趋势翻译室

把行业趋势翻译成普通用户、产品经理和设计团队能理解的语言。

适合选题：AI 家电、健康家居、场景智能、节能趋势、审美趋势、消费变化。

## 设计策略观察

拆解产品如何通过定位、叙事、视觉、交互和体验建立差异化。

适合选题：产品定位、品牌表达、功能优先级、用户心智、体验路径。

## 产品经理学习笔记

用学习笔记的方式整理产品判断、需求分析、竞品观察和表达方法。

适合选题：需求洞察、PRD 思考、用户故事、功能取舍、产品复盘。

## 统一选题标准

- 是否有明确判断。
- 是否能连接产品和用户体验。
- 是否能用 45-60 秒讲清楚。
- 是否适合小红书 / 抖音的短视频表达。
